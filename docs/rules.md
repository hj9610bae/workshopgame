# 💼 교섭의 도박사들 : Deal or No Deal — 규칙서 v2.3

> 처음 접하는 노무 실무자도 5분 만에 이해할 수 있도록 정리한 최종 규칙입니다.
> 변경점은 맨 아래 [변경 이력](#변경-이력)을 참고하세요.

## 1. 게임 개요

**"노조 요구안의 타결 장벽을 넘어 회사의 교섭 주도권을 극대화하라!"**

- **세계관**: 여러분은 회사의 노무 담당 팀입니다. 노조가 제시한 12개 요구안을 전략적으로 타결해 교섭 성과를 높이세요.
- **인원**: 5개 팀(A~E), 팀당 약 6명
- **시간**: 약 60~70분 (규칙 설명 + 연습 1라운드 15분 + 5라운드 × 약 8분 + 시상·안건 공개 10분)
- **핵심 — 막타 시스템**: 안건마다 '노조 요구 수치'가 있습니다. 각 팀이 제시안 카드로 수치를 깎고, **수치를 0 이하로 만든 팀이 그 안건의 보상을 독식**합니다.

### 진행 방식
- **프로젝터 화면(`board.html`)**: 모든 참가자가 함께 보는 화면. 순서, 테이블, 점수, 결과가 표시됩니다.
- **진행자 창(`board.html?console`)**: 진행자 노트북에만 띄우는 비공개 창. 포스트잇 입력, 스카우터, 남은 수치·보유 카드 확인
- 팀은 상의해서 **포스트잇**에 제안을 적어 보조자에게 냅니다. 특수 카드는 **실물 카드**로 나눠 줍니다.
- 팀이 가진 카드와 스카우터 결과는 프로젝터 화면에 나오지 않습니다.

## 2. 자원과 카드

### 💰 교섭 주도권 (단일 자원)
- 시작: 팀당 **10점**
- **순서 결정**: 주도권이 높은 팀부터 제안합니다.
- **아이템 구매**: 아이템을 쓰면 주도권이 **차감**됩니다. (보유한 점수 이상은 쓸 수 없음)
- **우승 기준**: 5라운드 종료 후 주도권이 가장 높은 팀이 우승합니다.
  → 지금 아이템을 쓰면 그만큼 우승 점수가 줄어든다는 점을 기억하세요.

### 🃏 제시안 카드 (5종)
매 라운드 **카드 1장**을 **테이블 1곳**에 냅니다.

> 게임 설명 화면에는 **기본 제시안만** 소개합니다. 특수 카드 4종은 이름·효과 모두 비공개이고, 얻은 팀에게만 진행자가 알려 줍니다. (아래 표는 진행자용)

| 카드 | 효과 | 사용 |
|---|---|---|
| **기본 제시안** | 요구 수치 **2** 감소 | 영구 소지, 매 라운드 사용 가능 |
| **전격 타결** | 요구 수치 **6** 감소 | 1회용 |
| **실무 교섭 병행** | **다음 라운드 시작 시** 요구 수치 **10** 감소 (5라운드에 내면 발동하지 않음) | 1회용 · 비공개 |
| **홍보물 발행** | 테이블에 부착. **매 라운드 종료 시** 요구 수치 **1** 감소 (게임 끝까지 유지) | 1회용 · 공개 |
| **안건 보류** | **이번 라운드** 그 테이블에 대한 **모든 제안 무효** (순번과 관계없이 가장 먼저 적용) | 1회용 |

- **시작 카드**: 기본 제시안만 가지고 시작합니다.
- **특수 카드는 전리품**입니다. 안건을 합의(막타)하면 그 안건에 걸린 특수 카드를 받습니다. 개수 제한은 없습니다.
- 전리품은 안건과 따로 정하고, **테이블에 오르는 순서대로 앞쪽 안건**에 하나씩 붙입니다: **홍보물 발행 → 안건 보류 → 전격 타결 → 전격 타결 → 실무 교섭 병행** (검진비 → 난임시술 → 체육대회 → 전기차 → 근속/건강)
- 테이블에는 어떤 카드인지 밝히지 않고 **'특수 카드'**로만 표시합니다. 합의 발표도 "특수 카드 1장 획득"까지만 공개합니다.

#### 카드 공통 원칙
1. **모든 카드는 '테이블'에 겁니다.** 그 사이 안건이 합의되어 바뀌면 새 안건에 적용됩니다.
2. **카드 효과로 합의되면 카드를 건 팀이 보상을 받습니다.** (실무 교섭 병행, 홍보물 포함)
3. 0 아래로 넘친 수치는 사라집니다. (다음 안건으로 넘어가지 않음)
4. **보류된 테이블**은 이번 라운드 동안 어떤 감소 효과도 받지 않습니다. 그 테이블에 낸 특수 카드는 돌려받고, 홍보물은 그 라운드만 쉽니다. (라운드 시작 때 발동하는 실무 교섭 병행은 보류보다 먼저 처리됩니다.)

### 💡 주도권 아이템 (제출 시간에 진행자에게 신청)

| 아이템 | 비용 | 효과 |
|---|---|---|
| **속마음 스카우터** | 주도권 −1 | 테이블 1곳의 **현재 남은 요구 수치**를 우리 팀에게만 보여줍니다. 여러 번 사용 가능 |
| **새치기 제안** | 주도권 −2 | 이번 라운드 제안 순번(1~5위)을 원하는 자리로 변경 |

**🔍 속마음 스카우터: 언제, 어떻게**
1. 제출 시간(3분) 중 언제든, 몇 번이든 진행자에게 "N번 테이블 스카우터"를 신청합니다.
2. 팀 대표가 진행자 노트북(진행자 창)으로 와서 스카우터 팝업의 **'누르고 있기'**를 직접 누르는 동안만 숫자를 봅니다. 손을 떼면 다시 가려집니다.
3. 결과를 보고 제출 용지를 쓰거나 고쳐서 내면 됩니다.
- 확인 시점의 값입니다. 이번 라운드에 앞 순번 팀이 먼저 깎으면 내 차례에는 더 줄어 있을 수 있습니다.

**⚡ 새치기 제안: 언제, 어떻게**
1. 포스트잇에 [팀 + 테이블 + 카드]와 함께 **"새치기 N번째"**를 적습니다. (1번째 ~ 마지막 모두 가능: 막타를 노려 뒤로 갈 수도 있음)
2. 다른 팀은 누가 새치기했는지 모른 채 각자 제출합니다.
3. 모든 용지를 입력하고 제안 공개를 시작하면, 첫 화면에 **"새치기 발생! 새 순서: …"**가 공개됩니다.
4. 바뀐 순서대로 제안이 적용됩니다.
- **2팀 이상 같은 자리를 원하면**: 주도권(제안 공개 시점)이 높은 팀이 그 자리를 차지하고, 밀린 팀은 **바로 다음 빈자리**로 갑니다(뒤에 빈자리가 없으면 앞쪽 가장 가까운 빈자리). 주도권이 같으면 원래 순번이 앞인 팀이 우선. 새치기하지 않은 팀은 남은 자리를 원래 순서대로 채웁니다.
  - 예) 원래 순서 A(14)·B(12)·C(10)·D(9)·E(8), D·E가 모두 "1번째" → D 1번째, E 2번째 → **D → E → A → B → C**
- 밀려서 원하는 자리를 못 얻어도 비용(−2)은 차감됩니다. 주도권이 2 미만이면 새치기는 실패하고 원래 순번 그대로입니다.
- 아이템 비용은 사용 즉시 차감되며, 이번 라운드 순서에는 영향을 주지 않습니다.

## 3. 안건 (12개: 테이블 3 + 대기열 8 + 최종 교섭 1)

**공개 정보**: 안건 이름(픽토그램), **노조 요구안**, 합의 보상(주도권, 특수 카드가 걸렸는지)
**비공개 정보 (블라인드)**: 처음 요구 수치와 현재 남은 요구 수치(스카우터로만 확인), **회사 제시안(타결 내용)**, 전리품이 어떤 특수 카드인지
- 참가자는 **노조 요구안의 크기와 보상**을 보고 요구 수치를 추측합니다. 대체로 보상이 클수록 수치도 크지만, **겉보기와 다른 안건(페이크)**이 2개 숨어 있습니다.
  - 😰 **전기차**: 작아 보이고 보상도 +2뿐인데 요구 수치 8 (실제 교섭의 난항)
  - 🤝 **복지기금**: 200억 출연으로 커 보이고 보상 +7인데 요구 수치 3 (원만한 노사관계로 쉬운 합의)
- 테이블에서 합의된 안건은 사라지지 않고 **테이블 뒤쪽에 희미하게 쌓여** 어느 팀이 가져갔는지 남습니다.
- 안건이 **합의되는 순간** 그 안건이 **어떻게 타결됐는지(회사 제시안)**, 처음 요구 수치, **깎인 이력**(어느 팀이 얼마나 깎았는지, 순서대로)이 공개됩니다. 합의되지 않은 안건의 이력은 끝까지 공개되지 않습니다.
- 안건 번호는 쓰지 않습니다.
- 아래 표의 회사 제시안·요구 수치·전리품은 **진행자만** 봅니다.

합의된 안건은 사라지고, 그 테이블에 대기열의 다음 안건이 즉시 들어옵니다. 대기열이 비면 테이블도 비어 있게 됩니다.

### 🏁 최종 교섭: 성과급
- 성과급은 대기열에 들어가지 않는 **별도의 4번 테이블**입니다. **4라운드 시작 시 열리며**, 1~3번 테이블의 진행 상황(대기열이 어디까지 왔는지)과는 무관합니다.
- 1~3번 테이블은 그대로 기존 방식(합의 → 대기열에서 다음 안건 보충)으로 진행됩니다.
- 4~5라운드에는 테이블이 4개가 되며, 성과급도 다른 안건과 똑같이 막타를 친 팀이 보상을 받습니다.
- 성과급이 합의되면 4번 테이블은 닫힙니다(보충 없음). 같은 라운드에 뒤 순번 팀이 4번 테이블에 낸 제안은 무효가 됩니다.
- 5라운드가 끝날 때까지 합의되지 않으면 아무도 보상을 받지 못합니다.
- 사회자 화면에는 처음부터 "4라운드 최종 교섭 개시: 성과급(+10)"을 예고로 띄워 둡니다.

## 4. 라운드 진행 (총 5라운드)

| 단계 | 내용 | 화면 |
|---|---|---|
| ⓪ 최종 교섭 개시 | 4라운드에만: 성과급 4번 테이블 오픈 | 사회자 화면 |
| ① 실무 교섭 발동 | 지난 라운드에 낸 '실무 교섭 병행'이 순서대로 발동 (합의 시 보상 지급) | 사회자 화면 |
| ② 순서 발표 | 주도권 높은 순 1~5위. **동점이면 지난 라운드에 뒤 순번이었던 팀 우선**, 1라운드는 무작위 | 사회자 화면 |
| ③ 비공개 제출 (3분) | 팀이 포스트잇에 [팀 + 테이블 + 카드 (+ 새치기)]를 적어 보조자에게 제출. 화면에 작성 예시와 스카우터 안내가 뜸. 이 시간에 스카우터 사용 가능. 시간 내 미제출 시 이번 라운드는 패스 | 프로젝터 · 진행자 창 |
| ④ 제안 공개 | 새치기가 있으면 바뀐 순서를 먼저 공개. **안건 보류를 먼저 적용**한 뒤, 1위 팀부터 차례로 적용. 사회자 화면에는 **합의 여부만** 표시 (낸 카드와 남은 수치는 비공개). 합의된 안건은 타결 내용, 처음 요구 수치, 깎인 이력 공개 | 사회자 화면 |
| ⑤ 라운드 종료 | 홍보물 효과 적용 → 보류 해제 → 점수 현황 표시 (홍보물로 합의되면 그 합의만 발표) | 사회자 화면 |

**합의(막타) 시**: 해당 팀이 보상 획득 → 안건 제거 → 대기열 다음 안건이 테이블에 등장 → 뒤 순번 팀이 그 테이블을 골랐다면 **새 안건을 자동 공격**

**최종 순위**: 5라운드 후 주도권 순. 동점이면 합의한 안건 수가 많은 팀, 그래도 같으면 공동 순위.

**마지막 공개**: 순위 발표 뒤 모든 안건의 실제 요구 수치·보상·합의 팀을 공개하고, 페이크 안건 2개를 강조하며 메시지를 전합니다.
> "별것 아닌 안건이라도 실제 교섭에서는 난항을 겪을 수 있고, 중요한 안건이라도 원만한 노사관계를 바탕으로 쉽게 합의할 수 있습니다." 

## 5. 예시 1라운드

> 현장에서는 설명 슬라이드 뒤에 **연습 게임 1라운드**를 실제 화면으로 진행합니다. 연습 게임은 안건 순서·전리품을 무작위로 정하고, 요구 수치는 보상 −1~+2(최소 2)의 연습용 값을 써서 실제 게임의 배치·수치가 드러나지 않습니다. 연습 점수는 실제 게임에 이어지지 않습니다.
> 아래 표는 실제 배치로 계산한 진행자용 참고입니다.

모든 팀이 기본 제시안만 가지고 시작합니다.
순서(추첨): A → B → C → D → E

| 순번 | 제출 (비공개) | 적용 결과 | 사회자 화면 |
|---|---|---|---|
| A | 1번 / 기본 제시안 | 검진비 2 → 0 **합의!** A +2점(12), 특수 카드(홍보물) 획득. 1번에 전기차(4) 등장 | 🎉 A팀, 검진비 합의 · 특수 카드 1장 획득 (타결: (수면비) 5만 원 인상 / 요구 수치 2 ➔ A −2) |
| B | 1번 / 기본 제시안 | 검진비를 노렸지만 새로 온 **전기차**를 공격: 8 → 6 | B팀 제안 완료 |
| C | 2번 / 기본 제시안 | 난임시술 3 → 1 | C팀 제안 완료 |
| D | 2번 / 기본 제시안 | 난임시술 1 → −1 **합의!** D +2점(12), 특수 카드(안건 보류) 획득. 2번에 근속/건강(5) 등장 | 🎉 D팀, 난임시술 합의 · 특수 카드 1장 획득 (타결: 100% 지원 / 요구 수치 3 ➔ C −2 ➔ D −2) |
| E | 3번 / 기본 제시안 | 체육대회 3 → 1 | E팀 제안 완료 |

라운드 종료 후 점수: A 12 · D 12 · B 10 · C 10 · E 10

**2라운드 순서**: A·D 동점 → 1라운드에 뒤 순번이었던 D 우선 → **D, A**. B·C·E 동점 → **E, C, B**
최종: **D → A → E → C → B**

> C팀은 2번 테이블을 1까지 깎아놓고 D팀에게 막타를 뺏겼습니다. 합의 순간 공개된 이력으로 모두가 이 사실을 알게 됩니다. 이것이 이 게임의 핵심 긴장감입니다.
> 전기차(B −2)와 체육대회(E −2)는 아직 합의되지 않았으므로 이력이 공개되지 않습니다.
