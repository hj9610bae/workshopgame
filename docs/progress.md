## 2026-10-13 세션: 현장 진행 방식 추가
- 요청: QR·폰 없이 모두가 한 화면을 보고, 보조자가 손으로 걷은 교섭안을 입력/클릭해 진행(피망 맞고처럼 테이블이 보이는 화면). 시작 전에 게임 방식과 예시 라운드를 시각적으로 보여주기
- 구현: `board.html` (서버 없음, localStorage). 기존 `host.html`/`play.html`은 그대로 두고 첫 화면에서 현장 진행을 맨 위에 배치
  - 처음 화면: 참가 팀 선택·팀 이름 입력, 게임 설명 버튼
  - 게임 설명: 규칙 슬라이드 6장 → 예시 1라운드(규칙서 5장, 남은 수치 공개, 제출 용지·막타 도장·점수 변화 연출) → 마무리. ←/→, 점 클릭, 자동 재생(5초)
  - 진행: 순서 발표 → 제출 받기(2분 타이머) → 보조자 입력(팀별 테이블·카드·새치기·스카우터 버튼) → 제안 공개(한 건씩) → 다음 라운드 → 최종 결과
  - 비공개 처리: 입력 패널은 기본으로 가려져 있고 펼쳐야 보임. 스카우터 숫자는 '누르고 있는 동안'만 보임. **🖥 진행자 창**(`board.html?console`)을 열면 프로젝터 화면엔 조작부가 사라지고 진행자 창에서 입력·남은 수치·보유 카드·팀별 결과 기록을 봄
  - 되돌리기(최근 40단계), 새로고침해도 이어서 진행, 단축키 Space·→ / Ctrl+Z
- 정한 것: 튜토리얼 예시 숫자는 엔진으로 계산(규칙을 바꾸면 자동 반영, 테스트로 규칙서 5장과 일치 확인). 튜토리얼은 팀 이름 바꾸기를 적용하지 않음(설명문이 A~E 기준)

## 2026-10-02 세션에서 확정한 결정
- 기술 스택: Vite + TypeScript / Firebase RTDB + 익명 로그인 / GitHub Pages (`main` push 시 자동 배포)
- 진행 방식: 사회자 화면 하나를 모두가 보고, **팀 대표 1명만** 폰으로 제출 (5팀 × 약 6명)
- 규칙 주요 결정 (자세한 내용은 `docs/rules.md` 변경 이력)
  - 주도권: 아이템 사용 시 차감, 우승 기준
  - 남은 요구 수치 비공개 + 속마음 스카우터(−1)
  - 기본 제시안 2, 특수 카드는 시작 지급 없이 **합의 전리품으로만** 획득
  - 순번: 주도권 순 자동, 동점은 지난 라운드 뒤 순번 우선
  - 안건 보류: 이번 라운드 그 테이블의 모든 제안 무효(순번 무관, 가장 먼저 적용)
  - 성과급: 대기열과 별개인 4번 테이블, **4라운드 시작 시 개시**, 합의되면 닫힘
- 구현하며 정한 세부 사항
  - 게임 시작 시 대표가 접속한 팀만 참여 (2~3팀으로도 테스트 가능)
  - 실무 교섭 병행은 5라운드에 폰에서 선택 불가
  - 공개 연출은 합의/무효/홍보물 부착만 표시, 보류는 테이블만 공개(누가 썼는지 비공개)
  - 팀 결과 메시지는 사회자 화면에서 해당 사건이 공개된 뒤에 폰에 표시
