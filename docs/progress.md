- 진행 방식: 사회자 화면 하나를 모두가 보고, **팀 대표 1명만** 폰으로 제출 (5팀 × 약 6명)
- 규칙 주요 결정 (자세한 내용은 `docs/rules.md` 변경 이력)
  - 주도권: 아이템 사용 시 차감, 우승 기준
  - 남은 요구 수치 비공개 + 속마음 스카우터(−1)
  - 기본 제시안 2, 특수 카드는 시작 지급 없이 **합의 전리품으로만** 획득
  - 순번: 주도권 순 자동, 동점은 지난 라운드 뒤 순번 우선
  - 안건 보류: 이번 라운드 그 테이블의 모든 제안 무효(순번 무관, 가장 먼저 적용)
  - 성과급: 대기열과 별개인 4번 테이블, **4라운드 시작 시 개시**, 합의되면 닫힘
- 구현하며 정한 세부 사항
  - 게임 시작 시 대표가 접속한 팀만 참여 (2~3팀으로도 테스트 가능)
  - 실무 교섭 병행은 5라운드에 폰에서 선택 불가
  - 공개 연출은 합의/무효/홍보물 부착만 표시, 보류는 테이블만 공개(누가 썼는지 비공개)
  - 팀 결과 메시지는 사회자 화면에서 해당 사건이 공개된 뒤에 폰에 표시
