  - 비공개 처리: 입력 패널은 기본으로 가려져 있고 펼쳐야 보임. 스카우터 숫자는 '누르고 있는 동안'만 보임. **🖥 진행자 창**(`board.html?console`)을 열면 프로젝터 화면엔 조작부가 사라지고 진행자 창에서 입력·남은 수치·보유 카드·팀별 결과 기록을 봄
  - 되돌리기(최근 40단계), 새로고침해도 이어서 진행, 단축키 Space·→ / Ctrl+Z
- 정한 것: 튜토리얼 예시 숫자는 엔진으로 계산(규칙을 바꾸면 자동 반영, 테스트로 규칙서 5장과 일치 확인). 튜토리얼은 팀 이름 바꾸기를 적용하지 않음(설명문이 A~E 기준)
