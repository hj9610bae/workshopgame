# 오디세이아 : 귀환의 항해 — 1인 진행 큐시트

> 진행자 한 명이 노트북 자리에서 화면 조작·포스트잇 입력·멘트를 모두 맡는 기준입니다.
> 총 **약 95분** (오프닝 3 · 설명 7 · 연습 10 · 본 항해 60 · 스핑크스 5 · 결과 10). 시간은 목표치이며 실제로는 하루 5~7분 사이를 오갑니다.

---

## 1. 사전 준비 (시작 30분 전)

### 장비
- [ ] 노트북 + 프로젝터를 **확장 모드**로 연결, 프로젝터 해상도 **1920×1080**
- [ ] 프로젝터 쪽 브라우저에 `board.html`을 열고 **F11 전체화면**, 배율 **100%** (Ctrl+0)
  - 1280×800 프로젝터라면 67%, 1366×768이면 67%
- [ ] 프로젝터 화면 오른쪽 위 **'진행자 창'** 버튼 → 새 창이 뜨면 **노트북 화면으로 옮김**
  - 진행자 창이 열려 있으면 프로젝터에는 조작 버튼이 사라지고 화면만 보입니다
  - 진행자 창에서만 남은 생명력·보유 무기·공격 이력이 보입니다. **프로젝터 쪽으로 끌어가지 말 것**
- [ ] 인터넷 연결 확인 (글꼴을 CDN에서 불러옴)
- [ ] 표지 화면에서 참가 함대 체크(기본 A~E), 필요하면 함대 이름 입력

### 물품
- [ ] 함대별 포스트잇 + 펜 (5세트)
- [ ] 함대 이름표 A~E (테이블 위)
- [ ] **실물 특수 무기 카드** (실제 게임용 5장): 🏹 전갈 화살 1 · ⛓️ 쇠사슬 1 · 🔱 삼지창 2 · ⚡ 투척 창 1. 뒷면에 효과 설명
- [ ] **스핑크스 퀴즈 문제** 하·중·상 각 3문제 이상 (세 함대가 같은 난도를 고를 수 있음) + 정답지

### 단축키 (진행자 창이 선택된 상태에서)
| 키 | 동작 |
|---|---|
| **Space / → / PageDown** | 다음 단계 (설명 다음 장, 순서 발표, 제출 시작, 다음 공개, 다음 날 출항 …) |
| ← / PageUp | 설명 이전 장 |
| Esc | 설명 닫기 · 예지 팝업 닫기 |
| **Ctrl+Z** | 되돌리기 (잘못 누른 단계 취소) |

> 실수 방지를 위해 **'공격 공개'와 스핑크스 '결과 발표'는 Space로 넘어가지 않습니다.** 마우스로 직접 누릅니다.

## 3. 단계별 큐

### 0:00 오프닝 (3분) — 표지 화면
- 함대 배정, 함대별로 테이블에 이름표·포스트잇 배부
- 멘트: "트로이 전쟁이 끝났습니다. 여러분의 함대는 이제 고국 이타카로 돌아갑니다. 10일간의 항해 동안 신화 속 역경을 돌파하고, 가장 먼저 고국에 도착하는 함대가 우승합니다!"

### 0:03 항해 설명 (7분) — '항해 설명 보기' → Space로 넘김
| 장 | 제목 | 강조할 것 |
|---|---|---|
| 1 | 오디세이아 : 귀환의 항해 | 10일 뒤 **고국과의 거리가 가장 짧은** 함대 우승 |
| 2 | 고국과의 거리 | 모두 **30해리**, 단검(기본 무기)만 들고 출발 |
| 3 | 공격 순서 발표 | 고국에 가까운 함대부터. 같으면 전날 먼저 공격한 함대가 뒤로 |
| 4 | 해역과 대기열 | 해역의 역경만 공격 가능, **돌파하면 생명력만큼 전진** + 전리품 |
| 5 | 해역 및 무기 선택 (3분) | 포스트잇에 **함대 · 해역 번호 · 무기**. 특수 무기는 쓰면 사라짐. 효과는 가진 함대만 앎 |
| 6 | 공격 적용 ① | 남은 생명력·누가 어디 냈는지는 **비공개**. 넘친 공격력은 사라짐 |
| 7 | 공격 적용 ② | **마지막 일격**을 넣은 함대만 공개되고 보상 독식. 빈자리는 대기열 맨 위 역경이 채움 |
| 8 | 특수 아이템 | 👁️ 예지(+1해리): 제출 시간에 **진행자 자리로 와서** 확인 / 🌬️ 순풍(+2해리): 포스트잇에 "순풍 N번째" |
| 9 | 게임 종료 | 10일 끝, 거리 가장 짧은 함대 우승 |
| 10 | 연습 항해 2일 | 실제와 같은 화면, 역경 배치는 무작위. 거리는 이어지지 않음 |

> ⚠️ **말하지 않을 것**: 8일차 4번 해역(최종 결전), 7일차 뒤 스핑크스 이벤트

### 0:10 연습 항해 2일 (10분)
- 마지막 장의 **'연습 항해 시작'** 클릭 → 아래 **하루 사이클**과 똑같이 진행
- 1인 진행이라 제출 방식을 여기서 몸에 익히게 함: "포스트잇을 다 쓰면 **대표가 진행자 자리로 가져와 주세요**"
- 연습 중 전리품을 얻으면 실물 카드 대신 말로만 알려 줌 (실물 카드는 실제 게임용)
- 2일차 공개가 끝나면 **'연습 끝 · 실제 항해 준비하기'** → 표지 화면 → **'▶ 출항 (5함대)'**
  - 출항할 때마다 역경 배치가 새로 섞이므로 연습과 다릅니다

### 하루 사이클 (1~10일차, 하루 약 6분)

| 순서 | 진행자 창 버튼 (키) | 프로젝터 화면 | 진행자 할 일 · 멘트 |
|---|---|---|---|
| ① | **'N일차 출항 ▶'** (Space) | 새 날 시작 | (2일차부터) 전날 공개가 모두 끝난 뒤 |
| ② | **'다음 공개 ▶'** (Space) | ⚡ 투척 창 돌파 팝업 | 어제 던진 투척 창이 역경을 돌파했을 때만 나옴. 여럿이면 하나씩 |
| ③ | **'N일차 순서 발표 ▶'** (Space) | 순서 배너 | "오늘의 공격 순서는 ○ → ○ → … 입니다" |
| ④ | **'제출 받기 시작 (3분) ▶'** (Space) | 명령서 작성 가이드 + 3분 타이머 | "3분 안에 해역과 무기를 정해 주세요. 예지를 쓰려면 지금 오세요!" |
| ⑤ | (입력 패널) | 'n/5함대 입력 완료' | 포스트잇을 받는 대로 입력 (아래 **입력 요령**) |
| ⑥ | **'공격 공개 ▶'** — **직접 클릭** | 사건 배너 | 3분이 지나면 화면에 '제출 시간 종료'. 못 낸 함대는 오늘 쉼 |
| ⑦ | **'다음 공개 ▶'** (Space) 반복 | 공격 완료 / 돌파 배너 · 배가 전진 | 사건마다 멘트 (아래 **발표 멘트**) |
| ⑧ | (마지막 사건까지) | '오늘의 항해 끝' → 전갈 화살 돌파 | 다음 날로 |

#### ⑤ 입력 요령 (제출 3분 동안)
- 진행자는 **노트북 자리에 고정**. 대표가 포스트잇을 가져오면 받자마자 입력
- 진행자 창 입력 패널에서 함대 줄마다:
  - **해역**: 1번 / 2번 / 3번 (8일차부터 4번)
  - **무기**: 단검 / 삼지창 ×n / 투척 창 ×n — 가진 개수가 0이면 버튼이 눌리지 않음
  - **추가 카드**: 전갈 화살·쇠사슬 + 그 해역
  - **순풍**: "N번째" (+2해리)
  - 다 누르면 줄에 ✓, 잘못 넣었으면 '지우기'
- **특수 무기를 쓰면 실물 카드를 포스트잇과 함께 회수**
- **예지 신청**: 그 함대 줄의 '예지 +1해리 → N번' → 노트북 팝업의 **'누르고 있기'**를 **대표가 직접** 누르는 동안만 숫자가 보임 → Esc로 닫기. 여러 번 가능, 1회마다 1해리 후퇴
- 1인 진행 팁: 예지 대기 줄이 생기면 "포스트잇 먼저 내고 예지 보신 뒤 고쳐 내셔도 됩니다"

#### ⑦ 발표 멘트
- **공격 완료**: "○함대 공격 완료! 역경은 아직 버티고 있습니다."
- **돌파**: "○함대가 ○번 해역의 ○○○을(를) 돌파했습니다! 보상으로 ○해리 전진합니다. 전리품은 ○○!"
  - 돌파 도장 → 약 **6초 뒤 빈 해역에 새 역경이 자동으로 들어옴**. 멘트를 그 안에 마치면 자연스러움 (그 전에 Space를 누르면 바로 들어옴)
  - 전리품이 있으면 그 함대에 **실물 카드 전달** (다음 제출 시간에 줘도 됨)
- **순풍**: "제피로스의 순풍이 불었습니다! 오늘의 새 순서는 …"
- **쇠사슬(동결)**: "○함대가 쇠사슬로 ○번 해역을 동결했습니다! 오늘 이 해역의 공격은 모두 무효입니다."
- **투척 창 가로채기**: "○함대가 투척 창으로 ○함대의 돌파를 가로챘습니다!"
- **오늘의 항해 끝**: "오늘의 항해가 끝났습니다." (전갈 화살로 쓰러진 역경이 있으면 이어서 돌파 발표)
- ⚠️ **절대 말하지 않을 것**: 남은 생명력, 누가 어느 해역에 무엇을 냈는지 (진행자 창에만 보임)

## 4. 문제가 생겼을 때

| 상황 | 대처 |
|---|---|
| 버튼을 잘못 눌렀다 | **Ctrl+Z** (되돌리기). 여러 번 가능 |
| 입력을 잘못했다 (공개 전) | 그 함대 줄의 **'지우기'** 후 다시 입력 |
| 공개한 뒤에 입력 실수를 알았다 | Ctrl+Z로 제출 단계까지 되돌려 고친 뒤 다시 '공격 공개' (이미 본 사건은 다시 나옴) |
| 진행자 창을 닫아 버렸다 | 프로젝터 화면의 '진행자 창'으로 다시 열기. 진행 상황은 그대로 |
| 브라우저가 꺼졌다 / 새로고침 | 같은 노트북 같은 브라우저로 `board.html`을 열면 표지에서 **'이어서 진행'** (저장은 이 브라우저에만 됨) |
| 프로젝터 화면이 잘리거나 스크롤이 생김 | F11 전체화면 · Ctrl+0(100%) 확인, 해상도에 맞는 배율로 |
| 시간이 밀린다 | 제출 3분을 지켜 '공격 공개'를 바로 누르고, 사건 멘트를 짧게. 스핑크스는 '이벤트 건너뛰기' 가능 |
